仕組みUnder the hood

  • Plain JavaScript, HTML and CSS: no framework, no build step. A push to GitHub Pages is a release.
  • Offline first: a service worker keeps the app and its sound; audio is cached by content hash.
  • Every word spoken: 4,679 recorded clips in 28 bundles, loaded when needed.
  • Handwriting matched stroke by stroke, or read as a point cloud against every kana.
  • Drawn in code: every scene, toy and character is SVG and CSS.
  • Made for a phone: installable, a one-thumb wheel menu, light and dark.
  • Optional sync through Firebase, merged so nothing learned is lost.
  • 11,121 automated checks run before every release.
